# Computer Networks (CN) – Important Interview Questions & Answers

**Target Companies:** TCS, TCS Ignite, Wipro, Infosys, Accenture, Cognizant, Deloitte & Other IT Companies.

## 🔴 Priority 1 – Must Prepare

### 1. ⭐⭐⭐ What is a Computer Network?
A computer network is a group of interconnected devices that communicate and share data with each other.

**Example:** Computers connected in an office to share files and printers.

### 2. ⭐⭐⭐ What are the advantages of Computer Networks?
Computer networks allow data sharing, resource sharing, communication and centralized management.

**Example:** Employees sharing files through an office network.

### 3. ⭐⭐⭐ What are LAN, MAN and WAN?
- **LAN:** Covers a small area, such as a home or office.
- **MAN:** Covers a city or large campus.
- **WAN:** Covers large geographical areas, such as countries.

**Example:** Home Wi-Fi is LAN, while the Internet is WAN.

### 4. ⭐⭐⭐ What is the Internet?
The Internet is a global network of interconnected computer networks that allows users to communicate and share information.

**Example:** Browsing websites and sending emails.

### 5. ⭐⭐⭐ What is an IP Address?
An IP address is a unique logical address assigned to a device on a network to identify and communicate with it.

**Example:** `192.168.1.1`

### 6. ⭐⭐⭐ What is the difference between IPv4 and IPv6?
- **IPv4:** Uses a 32-bit address.
- **IPv6:** Uses a 128-bit address and supports a much larger number of devices.

**Example:** IPv4: `192.168.1.1`

### 7. ⭐⭐⭐ What is a MAC Address?
A MAC address is a hardware address assigned to a network interface for identification within a local network.

**Example:** `00:1A:2B:3C:4D:5E`

### 8. ⭐⭐⭐ What is the difference between IP Address and MAC Address?
An IP address is a logical address used for network communication, whereas a MAC address is a hardware address used for communication within a local network.

**Example:** IP identifies a device across networks, while MAC identifies its network interface on a local network.

### 9. ⭐⭐⭐ What is DNS?
DNS (Domain Name System) converts domain names into IP addresses.

**Example:** DNS helps a browser find the IP address of `google.com`.

### 10. ⭐⭐⭐ What is DHCP?
DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses and other network settings to devices.

**Example:** Your router assigns an IP address to your phone when it connects to Wi-Fi.

### 11. ⭐⭐⭐ What is a Router?
A router is a networking device that connects different networks and forwards data packets between them.

**Example:** A home Wi-Fi router connects your devices to the Internet.

### 12. ⭐⭐⭐ What is a Switch?
A switch connects multiple devices within a local network and forwards data to the correct device using MAC addresses.

**Example:** Connecting computers in an office network.

### 13. ⭐⭐⭐ What is the OSI Model?
The OSI Model is a seven-layer reference model that explains how data communication takes place over a network.

**Seven Layers:**
1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

### 14. ⭐⭐⭐ What is the TCP/IP Model?
The TCP/IP Model is a networking model that defines how data is transmitted over the Internet.

**Four Layers:**
1. Network Access
2. Internet
3. Transport
4. Application

### 15. ⭐⭐⭐ Difference between TCP and UDP?
- **TCP:** Connection-oriented, reliable and ensures ordered data delivery.
- **UDP:** Connectionless, faster and does not guarantee delivery.

**Example:** TCP is used in reliable file transfers, while UDP is commonly used in online gaming and live streaming.

## 🟡 Priority 2 – Important

### 16. ⭐⭐ What is a Protocol?
A protocol is a set of rules that controls communication between devices over a network.

**Example:** HTTP, HTTPS, TCP and FTP.

### 17. ⭐⭐ What is HTTP and HTTPS?
- **HTTP:** Used to transfer data between a browser and a web server.
- **HTTPS:** Secure version of HTTP that uses encryption.

**Example:** Online banking websites use HTTPS to protect data.

### 18. ⭐⭐ What is a Firewall?
A firewall is a security system that monitors and controls incoming and outgoing network traffic based on security rules.

**Example:** Blocking unauthorized network connections.

### 19. ⭐⭐ What is a Modem?
A modem converts signals to enable communication between a network and an Internet service provider.

**Example:** A modem helps connect a home network to an ISP.

### 20. ⭐⭐ What is Bandwidth?
Bandwidth is the maximum amount of data that can be transmitted over a network connection in a given time.

**Example:** A 100 Mbps Internet connection.

### 21. ⭐⭐ What is the difference between Hub and Switch?
- **Hub:** Sends incoming data to all connected devices.
- **Switch:** Sends data to the intended device using its MAC address.

**Example:** A switch is commonly used in office networks.

### 22. ⭐⭐ What is Packet Switching?
Packet switching is a method of data transmission in which data is divided into smaller packets and sent across a network.

**Example:** Data sent over the Internet is transmitted in packets.

### 23. ⭐⭐ What is Topology?
Network topology refers to the physical or logical arrangement of devices in a network.

**Common Types:**
- Bus
- Star
- Ring
- Mesh
- Tree

**Example:** In star topology, all devices connect to a central switch.

### 24. ⭐⭐ What is the difference between Public IP and Private IP?
- **Public IP:** Used to identify a network on the Internet.
- **Private IP:** Used for communication within a private network.

**Example:** A router may have a public IP and assign private IPs to phones and laptops.

### 25. ⭐⭐ What is Ping?
Ping is a network utility used to check whether another device is reachable and measure response time.

**Example:** `ping google.com`

## 📌 Preparation Strategy

- ⭐⭐⭐ Prepare all questions thoroughly with examples.
- ⭐⭐ Understand the definitions and differences.
- Memorize the **OSI Model's 7 layers** and **TCP/IP Model's 4 layers** in order.
- Practise basic networking commands such as `ping`, `ipconfig` and `tracert`.

**Goal:** Explain each important concept clearly in 30–45 seconds.
