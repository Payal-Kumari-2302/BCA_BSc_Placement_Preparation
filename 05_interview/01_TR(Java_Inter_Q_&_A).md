## 1. Introduction to Java

**Definition:** Java is a high-level, class-based, object-oriented programming language.

### History of Java

- **1991:** Java development started.
- **Original Name:** Oak.
- **Founder:** James Gosling.
- **1995:** Officially released as Java.
- **Developed By:** Sun Microsystems.
- **2010:** Oracle acquired Sun Microsystems.

### Features of Java

1. Platform Independent
2. Object-Oriented
3. Secure
4. Robust
5. Multithreaded
6. Portable
7. High Performance
8. Dynamic

### Advantages

1. Platform-independent execution.
2. Rich libraries and frameworks.
3. Strong security features.
4. Automatic memory management.
5. Suitable for enterprise applications.

### Disadvantages

1. High memory consumption.
2. More code required.
3. Requires JVM for execution.
4. Slower startup in some applications.
5. Less direct memory control.

## 2. 🔴 PRIORITY 1 – Most Important Interview Questions

### 1. ⭐ What is JVM?
**Answer:** JVM executes Java bytecode.

### 2. ⭐ What is JDK?
**Answer:** JDK provides tools to develop and compile Java programs.

### 3. ⭐ What is JRE?
**Answer:** JRE provides the environment required to run Java programs.

### 4. ⭐ Difference between JDK, JRE and JVM?
**Answer:**
- JDK: Develops Java programs.
- JRE: Provides runtime environment.
- JVM: Executes bytecode.

### 5. ⭐ What is Bytecode?
**Answer:** Bytecode is the intermediate code generated by the Java compiler.

### 6. ⭐ What is the `static` Keyword?
**Answer:** Static members belong to the class rather than individual objects.

### 7. ⭐ What is the `final` Keyword?
**Answer:** Final prevents variable modification, method overriding or class inheritance.

### 8. ⭐ What are Access Modifiers?
**Answer:** They control the visibility of Java classes, methods and variables.

**Types:** `public`, `private`, `protected`, `default`.

### 9. ⭐ What is Collection Framework?
**Answer:** It provides interfaces and classes to manage groups of objects.

### 10. ⭐ What is ArrayList?
**Answer:** ArrayList is a resizable array implementation of the List interface.

### 11. ⭐ What is HashMap?
**Answer:** HashMap stores data in key-value pairs with unique keys.

### 12. ⭐ What is HashSet?
**Answer:** HashSet stores unique elements without guaranteeing insertion order.

### 13. ⭐ What is a Wrapper Class?
**Answer:** Wrapper classes represent primitive data types as objects.

**Example:** `int` → `Integer`.

### 14. ⭐ What is Autoboxing?
**Answer:** Automatic conversion of primitive values into wrapper objects.

### 15. What is Unboxing?
**Answer:** Automatic conversion of wrapper objects into primitive values.

### 16. ⭐ Difference between `==` and `.equals()`?
**Answer:**
- `==`: Compares primitive values or object references.
- `.equals()`: Compares object content when properly implemented.

## 3. 🟡 PRIORITY 2 – Additional Important Questions

### 17. What is a Package?
**Answer:** A package groups related Java classes and interfaces.

### 18. What is Enum?
**Answer:** Enum defines a fixed set of constants.

### 19. What is an Annotation?
**Answer:** An annotation provides metadata about Java code.

**Example:** `@Override`.

### 20. Difference between String, StringBuilder and StringBuffer?

| String | StringBuilder | StringBuffer |
|---|---|---|
| Immutable | Mutable | Mutable |
| Not synchronized | Not synchronized | Synchronized |
| Less suitable for repeated modifications | Faster for modifications | Thread-safe modifications |

### 21. Difference between Primitive and Reference Data Types?
**Answer:**
- Primitive: Stores basic values.
- Reference: Stores references to objects.

### 22. What is Constructor Overloading?
**Answer:** Defining multiple constructors with different parameters.

### 23. Difference between `final`, `finally` and `finalize()`?

| Keyword | Meaning |
|---|---|
| `final` | Restricts modification, overriding or inheritance. |
| `finally` | Executes cleanup code after try-catch. |
| `finalize()` | Deprecated method historically associated with garbage collection. |

## 4. ⭐ Difference Between C, C++, Java and Python

| Feature | C | C++ | Java | Python |
|---|---|---|---|---|
| Developed By | Dennis Ritchie | Bjarne Stroustrup | James Gosling | Guido van Rossum |
| Year | 1972 | 1985 | 1995 | 1991 |
| Programming Type | Procedural | Procedural + OOP | Class-based OOP | Multi-paradigm |
| Execution | Compiler | Compiler | JVM (Bytecode) | Interpreter (commonly) |
| Syntax | Complex | Complex | Moderate | Simple |
| Platform | Platform Dependent | Platform Dependent | Platform Independent | Cross-platform |
| Memory Management | Manual | Manual + Automatic | Automatic | Automatic |
| Pointer | Supported | Supported | No Explicit Pointers | No Explicit Pointers |
| Multiple Inheritance | Not Applicable | Supported | Through Interfaces | Supported |
| OOP Support | No | Yes | Yes | Yes |
| Speed | Very Fast | Very Fast | Generally Fast | Generally Slower |
| File Extension | `.c` | `.cpp` | `.java` | `.py` |

|---|---|---|
| C | `scanf()` | `printf()` |
