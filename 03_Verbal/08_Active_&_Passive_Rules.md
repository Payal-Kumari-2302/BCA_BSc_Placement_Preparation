# ACTIVE & PASSIVE VOICE – Important Grammar Rules & Error Spotting

**Target Companies:** TCS, TCS Ignite, Wipro, Infosys, Accenture, Cognizant, Deloitte & Other IT Companies  
**Target Audience:** BCA Students & Freshers

## Definition

**Active Voice:** The subject performs the action.

**Passive Voice:** The subject receives the action.

Example:
- Active: She writes a letter.
- Passive: A letter is written by her.

# 🔴 PART 1 – Important Rules & Structures

### Rule 1: Basic Structure
- Active: Subject + Verb + Object
- Passive: Object + Be Verb + V3 + By + Subject

### Rule 2: Present Simple
- Active: Subject + V1(s/es) + Object
- Passive: Object + Is/Am/Are + V3 + By + Subject

Example: She writes a letter → A letter is written by her.

### Rule 3: Present Continuous
- Active: Subject + Is/Am/Are + V-ing + Object
- Passive: Object + Is/Am/Are + Being + V3

Example: She is writing a letter → A letter is being written by her.

### Rule 4: Present Perfect
- Active: Subject + Has/Have + V3 + Object
- Passive: Object + Has/Have + Been + V3

Example: She has written a letter → A letter has been written by her.

### Rule 5: Past Simple
- Active: Subject + V2 + Object
- Passive: Object + Was/Were + V3

Example: She wrote a letter → A letter was written by her.

### Rule 6: Past Continuous
- Active: Subject + Was/Were + V-ing + Object
- Passive: Object + Was/Were + Being + V3

Example: She was writing a letter → A letter was being written by her.

### Rule 7: Past Perfect
- Active: Subject + Had + V3 + Object
- Passive: Object + Had + Been + V3

Example: She had written a letter → A letter had been written by her.

### Rule 8: Future Simple
- Active: Subject + Will + V1 + Object
- Passive: Object + Will + Be + V3

Example: She will write a letter → A letter will be written by her.

### Rule 9: Modal Verbs
- Active: Subject + Modal + V1 + Object
- Passive: Object + Modal + Be + V3

Example: She can solve the problem → The problem can be solved by her.

### Rule 10: Imperative Sentences
- Active: V1 + Object
- Passive: Let + Object + Be + V3

Example: Open the door → Let the door be opened.

### Rule 11: Negative Sentences
- Active: Subject + Do/Does/Did + Not + V1 + Object
- Passive: Object + Is/Am/Are/Was/Were + Not + V3

Example: He does not complete the work → The work is not completed by him.

### Rule 12: Interrogative Sentences
- Active: Helping Verb + Subject + Main Verb + Object?
- Passive: Helping Verb + Object + Be/Been/Being + V3?

Example: Did he write a letter? → Was a letter written by him?

### Rule 13: Perfect Continuous Tenses
Present Perfect Continuous and Past Perfect Continuous generally do not have natural passive forms in standard English.

### Rule 14: Intransitive Verbs
Verbs without an object cannot normally be changed into passive voice.

Example: He sleeps. (No passive voice)

# 🔴 PART 2 – Important Passive Voice Structures

| Tense | Passive Structure |
|---|---|
| Present Simple | Is/Am/Are + V3 |
| Present Continuous | Is/Am/Are + Being + V3 |
| Present Perfect | Has/Have + Been + V3 |
| Past Simple | Was/Were + V3 |
| Past Continuous | Was/Were + Being + V3 |
| Past Perfect | Had + Been + V3 |
| Future Simple | Will + Be + V3 |
| Modal | Modal + Be + V3 |

# 🔴 PART 3 – Important Error Spotting Questions

### Q1.
The letter (A) / was wrote (B) / by Rahul yesterday (C) / No error (D).

**Answer:** B – was written  
**Rule:** Was/Were + V3.

### Q2.
The work (A) / is being complete (B) / by the employees (C) / No error (D).

**Answer:** B – is being completed  
**Rule:** Is/Am/Are + Being + V3.

### Q3.
The project (A) / has been complete (B) / by the team (C) / No error (D).

**Answer:** B – has been completed  
**Rule:** Has/Have + Been + V3.

### Q4.
The rooms (A) / is cleaned (B) / every day (C) / No error (D).

**Answer:** B – are cleaned  
**Rule:** Plural subject + Are + V3.

### Q5.
The match (A) / will played (B) / tomorrow (C) / No error (D).

**Answer:** B – will be played  
**Rule:** Will + Be + V3.

### Q6.
The problem (A) / can solved (B) / easily (C) / No error (D).

**Answer:** B – can be solved  
**Rule:** Modal + Be + V3.

### Q7.
The work (A) / was being do (B) / by the workers (C) / No error (D).

**Answer:** B – was being done  
**Rule:** Was/Were + Being + V3.

### Q8.
A letter (A) / has written (B) / by her (C) / No error (D).

**Answer:** B – has been written  
**Rule:** Has/Have + Been + V3.

### Q9.
The door (A) / should opened (B) / immediately (C) / No error (D).

**Answer:** B – should be opened  
**Rule:** Modal + Be + V3.

### Q10.
The thief (A) / was arrested (B) / by the police yesterday (C) / No error (D).

**Answer:** D – No error.

### Q11.
The homework (A) / is completed (B) / by the students yesterday (C) / No error (D).

**Answer:** B – was completed  
**Rule:** Past time expression + Past Simple Passive.

### Q12.
The cake (A) / was baked (B) / by my mother (C) / No error (D).

**Answer:** D – No error.

# 🔴 PART 4 – Important Placement Points

1. Passive voice always uses V3 of the main verb.
2. Identify the tense before selecting the helping verb.
3. Use Being in continuous passive structures.
4. Use Been in perfect passive structures.
5. Use Be after modals in passive voice.
6. Only transitive verbs can normally form passive voice.
7. The use of By + Subject is not compulsory when the doer is unknown or unimportant.

**Placement Preparation Priority:** Focus on tense-based passive structures, Modal + Be + V3, Being vs Been, V2 vs V3, subject-verb agreement and active-to-passive conversion.
