# Operating System (OS) – Important Interview Questions & Answers

**Target Companies:** TCS, TCS Ignite, Wipro, Infosys, Accenture, Cognizant & Deloitte.

## 🔴 Priority 1 – Most Important

### 1. ⭐⭐⭐ What is an Operating System?
An Operating System is system software that acts as an interface between users and computer hardware.

**Example:** Windows, Linux and Android.

### 2. ⭐⭐⭐ What are the main functions of an Operating System?
The main functions are process, memory, file, device and security management.

**Example:** Windows manages RAM, applications and connected devices.

### 3. ⭐⭐ What are the different types of Operating Systems?
The major types are Batch, Time-Sharing, Multiprogramming, Multiprocessing, Real-Time and Distributed OS.

**Example:** Real-Time OS is used in industrial control systems.

### 4. ⭐⭐⭐ What is a Process?
A process is a program currently being executed by the CPU.

**Example:** Opening Google Chrome.

### 5. ⭐⭐⭐ What is the difference between Program and Process?
- **Program:** A set of instructions stored on a computer.
- **Process:** A program currently in execution.

**Example:** Installed Chrome is a program; running Chrome is a process.

### 6. ⭐⭐⭐ What is a Thread?
A thread is the smallest unit of execution within a process.

**Example:** A browser uses threads to load webpages and handle user interactions.

### 7. ⭐⭐⭐ What is the difference between Process and Thread?
- **Process:** An independent execution unit with its own memory space.
- **Thread:** A lightweight execution unit that shares process memory.

**Example:** A browser is a process, and its tasks can run in separate threads.

### 8. ⭐⭐⭐ What is Multitasking?
Multitasking allows an operating system to run multiple applications seemingly at the same time.

**Example:** Listening to music while browsing.

### 9. ⭐⭐⭐ What is CPU Scheduling?
CPU Scheduling is the process of selecting a process for CPU execution.

**Example:** The OS decides which application gets CPU time.

### 10. ⭐⭐⭐ What is Deadlock?
Deadlock occurs when processes wait indefinitely for resources held by each other.

**Example:** Two processes waiting for each other's locked resources.

### 11. ⭐⭐⭐ What is Memory Management?
Memory Management is the process of allocating and managing memory for running programs.

**Example:** Allocating RAM to multiple applications.

### 12. ⭐⭐⭐ What is Virtual Memory?
Virtual Memory uses secondary storage as an extension of RAM when physical memory is insufficient.

**Example:** Windows uses disk space to support memory requirements.

## 🟡 Priority 2 – Important

### 13. ⭐⭐⭐ What is Kernel?
The Kernel is the core component of an OS that manages hardware and system resources.

**Example:** Linux Kernel.

### 14. ⭐⭐ What is Booting?
Booting is the process of starting a computer and loading the operating system.

**Types:**
- Cold Booting: Starting a powered-off computer.
- Warm Booting: Restarting a running computer.

### 15. ⭐⭐ What is Paging?
Paging divides virtual memory into fixed-size pages and physical memory into frames.

**Example:** Loading program pages into available RAM frames.

### 16. ⭐⭐ What is Fragmentation?
Fragmentation is memory wastage caused by inefficient memory allocation.

**Types:**
- Internal: Unused space inside an allocated block.
- External: Free memory scattered into small blocks.

### 17. ⭐⭐ What is Context Switching?
Context Switching is the process of saving one process's state and switching CPU execution to another process.

**Example:** Switching CPU execution between applications.

### 18. ⭐⭐ What is a System Call?
A System Call allows a program to request services from the operating system.

**Example:** Requesting the OS to open a file.

### 19. ⭐⭐ What is Multiprogramming?
Multiprogramming keeps multiple programs in memory to improve CPU utilization.

**Example:** Executing another program while one waits for I/O.

### 20. ⭐⭐ What is Multiprocessing?
Multiprocessing uses two or more processors or CPU cores to execute tasks simultaneously.

**Example:** A multi-core processor running different tasks in parallel.

### 21. ⭐⭐⭐ What are CPU Scheduling Algorithms?
CPU Scheduling Algorithms determine which process gets CPU time and in what order.

**Important Types:**
- FCFS: First process to arrive gets CPU first.
- SJF: Process with the shortest execution time gets CPU first.
- Round Robin: Each process gets a fixed time slot.
- Priority Scheduling: Higher-priority process gets CPU first.

**Example:** FCFS works like a queue at a ticket counter.

### 22. ⭐⭐⭐ What are the different states of a Process?
A process passes through five main states:

1. New – Process is created.
2. Ready – Waiting for CPU.
3. Running – Currently executing.
4. Waiting – Waiting for an event or I/O.
5. Terminated – Execution is completed.

### 23. ⭐⭐ What is a Semaphore?
A Semaphore is a synchronization mechanism used to control access to shared resources.

**Example:** Managing access to limited parking spaces.

### 24. ⭐⭐ What is a Mutex?
A Mutex is a locking mechanism that allows only one thread at a time to access a shared resource.

**Example:** Only one person can use a single-user printer at a time.
