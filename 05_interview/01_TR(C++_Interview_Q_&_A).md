# C++ – Important Interview Questions & Answers

**Target Companies:** TCS, TCS Ignite, Wipro, Infosys, Accenture, Cognizant, Deloitte & Other IT Companies.

**Target Audience:** BCA Students & Freshers

**Note:** Python is my primary programming language. C++ is included for basic programming and OOP interview preparation.

## 🔴 Priority 1 – Must Prepare

### 1. ⭐⭐⭐ What is C++?
C++ is a general-purpose programming language that supports both procedural and object-oriented programming.

### 2. ⭐⭐⭐ What is the difference between C and C++?

| C | C++ |
|---|---|
| Procedural programming language. | Supports procedural and object-oriented programming. |
| Does not support classes and objects. | Supports classes and objects. |
| Does not support function overloading. | Supports function overloading. |
| Uses `printf()` and `scanf()`. | Uses `cout` and `cin`. |

### 3. ⭐⭐⭐ What is OOP?
OOP is a programming approach based on classes and objects.

### 4. ⭐⭐⭐ What is a Class?
A class is a blueprint used to create objects.

### 5. ⭐⭐⭐ What is an Object?
An object is an instance of a class.

### 6. ⭐⭐⭐ What are the four pillars of OOP?

1. **Encapsulation:** Wrapping data and functions into one unit.
2. **Inheritance:** Acquiring properties of another class.
3. **Polymorphism:** One name with multiple forms.
4. **Abstraction:** Hiding implementation details.

### 7. ⭐⭐⭐ What is a Constructor?
A constructor is a special member function automatically called when an object is created.

### 8. ⭐⭐⭐ What is a Destructor?
A destructor is a special member function automatically called when an object is destroyed.

### 9. ⭐⭐⭐ What is Inheritance?
Inheritance allows one class to acquire properties and functions of another class.

### 10. ⭐⭐⭐ What is Polymorphism?
Polymorphism means one name with multiple forms of behaviour.

### 11. ⭐⭐⭐ What is the difference between Overloading and Overriding?

| Overloading | Overriding |
|---|---|
| Same function name with different parameters. | Redefining a base class function in a derived class. |
| Usually occurs within the same class. | Requires inheritance. |
| Compile-time polymorphism. | Runtime polymorphism (with virtual functions). |

### 12. ⭐⭐⭐ What is a Pointer?
A pointer is a variable that stores the memory address of another variable.

## 🟡 Priority 2 – Important

### 13. ⭐⭐ What are Access Specifiers?
They control the accessibility of class members.

**Types:** Public, Private and Protected.

### 14. ⭐⭐ What is the difference between Structure and Class?

| Structure | Class |
|---|---|
| Members are public by default. | Members are private by default. |
| Uses the `struct` keyword. | Uses the `class` keyword. |
| Commonly used for grouping data. | Commonly used for OOP. |

### 15. ⭐⭐ What is Function Overloading?
Defining multiple functions with the same name but different parameters.

### 16. ⭐⭐ What is a Virtual Function?
A virtual function supports runtime polymorphism in C++.

### 17. ⭐⭐ What is the difference between Call by Value and Call by Reference?

| Call by Value | Call by Reference |
|---|---|
| A copy of the value is passed. | The original variable is accessed through a reference. |
| Changes do not affect the original variable. | Changes affect the original variable. |
| Separate parameter storage is used. | The parameter refers to the original variable. |

### 18. ⭐⭐ What is Exception Handling?
It handles runtime errors using `try`, `catch` and `throw`.

### 19. ⭐⭐ What is Dynamic Memory Allocation?
Allocating memory during program execution using `new` and releasing it using `delete`.

### 20. ⭐⭐ What is the difference between Array and Pointer?

| Array | Pointer |
|---|---|
| Stores multiple elements of the same data type. | Stores a memory address. |
| Has a fixed size after creation. | Can point to different memory locations. |
| Array name generally represents its first element's address. | Pointer is a separate variable. |
