# CONDITIONALS & DEGREES OF COMPARISON – Important Grammar Rules & Error Spotting

**Target Companies:** TCS, TCS Ignite, Wipro, Infosys, Accenture, Cognizant, Deloitte & Other IT Companies  
**Target Audience:** BCA Students & Freshers

# 🔴 PART 1 – CONDITIONALS

## Definition
Conditional sentences express a condition and its possible result, usually using **If**.

## Rule 1: Zero Conditional
**Structure:** If + Subject + V1(s/es), Subject + V1(s/es)

Used for general truths and scientific facts.

Example: If you heat water, it boils.

## Rule 2: First Conditional
**Structure:** If + Subject + V1(s/es), Subject + Will + V1

Used for real and possible future situations.

Example: If you study hard, you will pass.

## Rule 3: Second Conditional
**Structure:** If + Subject + V2, Subject + Would + V1

Used for imaginary or unlikely present/future situations.

Example: If I were rich, I would travel the world.

## Rule 4: Third Conditional
**Structure:** If + Subject + Had + V3, Subject + Would Have + V3

Used for imaginary past situations that did not happen.

Example: If he had studied, he would have passed.

## Rule 5: Unless
**Structure:** Unless + Positive Clause = If + Negative Clause

Unless means if not. Do not normally use another negative in the unless clause.

Example: Unless you work hard, you will fail.

## Rule 6: Were
**Structure:** If + Subject + Were, Subject + Would + V1

Use were for hypothetical situations, including singular subjects.

Example: If I were you, I would accept the offer.

## Rule 7: Mixed Conditional
**Structure:** If + Subject + Had + V3, Subject + Would + V1

Used when a past condition has a present result.

Example: If I had studied medicine, I would be a doctor now.

## Rule 8: Do Not Use Will in the If-Clause
**Structure:** If + Present Simple, Will + V1

For ordinary first conditional sentences, use present simple in the if-clause, not will.

Example: If it rains, we will stay home.

# 🔴 PART 2 – DEGREES OF COMPARISON

## Definition
Degrees of Comparison are used to compare the qualities of people, places, animals or things.

## Rule 1: Positive Degree
**Structure:** Subject + As + Adjective + As + Object

Used to show equal comparison.

Example: Rahul is as tall as Amit.

## Rule 2: Negative Comparison
**Structure:** Subject + Not as/so + Adjective + As + Object

Used to show unequal comparison.

Example: Rahul is not as tall as Amit.

## Rule 3: Comparative Degree
**Structure:** Subject + Adjective-er / More + Adjective + Than + Object

Used to compare two people or things.

Example: Rahul is taller than Amit.

## Rule 4: Superlative Degree
**Structure:** Subject + The + Adjective-est / Most + Adjective

Used to compare one person or thing with a group of three or more.

Example: Rahul is the tallest boy in the class.

## Rule 5: Double Comparison
Never use more with an adjective already in its comparative form.

❌ She is more taller than me.  
✔ She is taller than me.

## Rule 6: Double Superlative
Never use most with an adjective already in its superlative form.

❌ He is the most tallest boy.  
✔ He is the tallest boy.

## Rule 7: Comparative + Than
**Structure:** Comparative Adjective + Than

Use than after comparative adjectives.

Example: This book is better than that one.

## Rule 8: One of the + Superlative
**Structure:** One of the + The + Superlative + Plural Noun

Example: He is one of the best players in the team.

## Rule 9: Senior / Junior / Superior / Inferior
**Structure:** Senior/Junior/Superior/Inferior + To

Use to instead of than after these adjectives.

Example: She is senior to me.

## Rule 10: Prefer
**Structure:** Prefer + Noun/Gerund + To + Noun/Gerund

Use to instead of than with prefer when comparing two choices.

Example: I prefer tea to coffee.

## Rule 11: The + Comparative, The + Comparative
**Structure:** The + Comparative + Subject + Verb, The + Comparative + Subject + Verb

Used to show that one change depends on another.

Example: The harder you work, the more you achieve.

## Rule 12: Irregular Comparison

| Positive | Comparative | Superlative |
|---|---|---|
| Good | Better | Best |
| Bad | Worse | Worst |
| Little | Less | Least |
| Much/Many | More | Most |
| Far | Farther/Further | Farthest/Furthest |
| Old | Older/Elder | Oldest/Eldest |

# 🔴 PART 4 – Important Error Spotting Questions

## Conditionals

### Q1.
If he (A) / will work hard (B) / he will succeed (C) / No error (D).

**Answer:** B – works hard  
**Rule:** First Conditional: If + Present Simple.

### Q2.
If I (A) / was you (B) / I would accept the offer (C) / No error (D).

**Answer:** B – were you  
**Rule:** Hypothetical condition: If + Were.

### Q3.
If she had studied (A) / she would have passed (B) / the examination (C) / No error (D).

**Answer:** D – No error.

### Q4.
Unless you (A) / do not study (B) / you will fail (C) / No error (D).

**Answer:** B – study  
**Rule:** Unless already means if not; avoid double negatives.

### Q5.
If he (A) / had worked hard (B) / he would pass the examination (C) / No error (D).

**Answer:** C – would have passed  
**Rule:** Third Conditional: Would have + V3.

### Q6.
If you (A) / heat ice (B) / it will melt (C) / No error (D).

**Answer:** C – it melts  
**Rule:** Zero Conditional: Present + Present.

## Degrees of Comparison

### Q7.
She is (A) / more intelligent (B) / than her brother (C) / No error (D).

**Answer:** D – No error.

### Q8.
He is (A) / the most tallest (B) / boy in the class (C) / No error (D).

**Answer:** B – the tallest  
**Rule:** Avoid double superlatives.

### Q9.
Rahul is (A) / senior than (B) / Amit (C) / No error (D).

**Answer:** B – senior to  
**Rule:** Senior + To.

### Q10.
She is (A) / one of the best student (B) / in the class (C) / No error (D).

**Answer:** B – one of the best students  
**Rule:** One of the + Superlative + Plural Noun.

### Q11.
This book is (A) / more better (B) / than that one (C) / No error (D).

**Answer:** B – better  
**Rule:** Avoid double comparatives.

### Q12.
I prefer tea (A) / than coffee (B) / in the morning (C) / No error (D).

**Answer:** B – to coffee  
**Rule:** Prefer X to Y.

### Q13.
The more you practice (A) / the most confident (B) / you become (C) / No error (D).

**Answer:** B – the more confident  
**Rule:** The + Comparative, The + Comparative.

### Q14.
No other city (A) / is as larger as (B) / Mumbai in this region (C) / No error (D).

**Answer:** B – is as large as  
**Rule:** As + Positive Degree + As.

### Q15.
He is (A) / better than any student (B) / in his class (C) / No error (D).

**Answer:** B – better than any other student  
**Rule:** Compare one member with the other members of the same group.
