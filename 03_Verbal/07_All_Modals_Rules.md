# MODALS – Important Grammar Rules & Error Spotting

**Target Companies:** TCS, TCS Ignite, Wipro, Infosys, Accenture, Cognizant, Deloitte & Other IT Companies  
**Target Audience:** BCA Students & Freshers

## Definition
Modals are helping verbs used to express ability, permission, possibility, necessity, advice, obligation and willingness.

# 🔴 PART 1 – Important Modal Rules

### Rule 1: Modal + V1
**Structure:** Subject + Modal + V1 + Object

A modal is always followed by the base form of the verb.

- She can **speak** English.
- He should **study** regularly.

❌ She can speaks English.

### Rule 2: No s/es with Modals
**Structure:** Subject + Modal + V1

Never add s/es to the verb after a modal, even with singular subjects.

- He can play cricket.
- She must work hard.

❌ He can plays cricket.

### Rule 3: Modal + Not
**Structure:** Subject + Modal + Not + V1

Use not immediately after a modal to make a negative sentence.

- You should not waste time.
- He cannot drive.

### Rule 4: Modal in Questions
**Structure:** Modal + Subject + V1 + Object?

Place the modal before the subject in interrogative sentences.

- Can you help me?
- Should we start now?

### Rule 5: Two Modals Together
Two pure modals cannot normally be used together in a sentence.

- He will be able to complete the task.
- She may have to leave.

❌ He will can do it.

### Rule 6: Modal + Have + V3
**Structure:** Subject + Modal + Have + V3

Used to express past possibility, regret, criticism or deduction.

- You should have studied.
- He might have missed the train.
- She must have forgotten.

### Rule 7: Modal + Be + V-ing
**Structure:** Subject + Modal + Be + V-ing

Used to express an action that may or should be continuing.

- He may be sleeping.
- She must be working.

### Rule 8: Modal + Be + V3
**Structure:** Subject + Modal + Be + V3

Used to form passive sentences.

- The work must be completed.
- The rules should be followed.

### Rule 9: Ought to
**Structure:** Subject + Ought to + V1

Always use to after ought.

- You ought to respect your parents.

❌ You ought respect your parents.

### Rule 10: Have to / Has to
**Structure:** Subject + Have/Has to + V1

Used to express necessity or obligation.

- I have to study.
- She has to attend the meeting.

### Rule 11: Had to
**Structure:** Subject + Had to + V1

Used to express past necessity or obligation.

- He had to leave early.
- They had to work hard.

### Rule 12: Used to
**Structure:** Subject + Used to + V1

Used to express past habits or repeated actions that no longer happen.

- I used to play football.
- She used to live here.

# 🔴 PART 2 – Important Modal Usage

| Modal | Main Usage | Example |
|---|---|---|
| Can | Present ability / Permission | I can swim. |
| Could | Past ability / Polite request | Could you help me? |
| May | Permission / Possibility | May I come in? |
| Might | Weak possibility | It might rain. |
| Shall | Suggestion / Future (I, We) | Shall we go? |
| Should | Advice / Duty | You should study. |
| Will | Future / Willingness | I will help you. |
| Would | Polite request / Past habit | Would you help me? |
| Must | Strong obligation / Necessity | You must obey the rules. |
| Ought to | Moral duty / Advice | You ought to help him. |
| Need | Necessity | You need not worry. |
| Dare | Courage / Challenge | How dare you speak? |

# 🔴 PART 3 – Important Error Spotting Questions
# MODALS – Error Spotting Questions

**Target Exams:** TCS Ignite, TCS NQT, Wipro, Infosys, Accenture, Cognizant & Deloitte.

### Q1.
She (A) / can speaks (B) / English fluently (C) / No error (D).

**Answer:** B – can speak  
**Rule:** Modal + V1.

### Q2.
You (A) / should to follow (B) / the instructions carefully (C) / No error (D).

**Answer:** B – should follow  
**Rule:** Should + V1.

### Q3.
He (A) / must completes (B) / his assignment today (C) / No error (D).

**Answer:** B – must complete  
**Rule:** Modal + V1.

### Q4.
They (A) / will can solve (B) / this problem easily (C) / No error (D).

**Answer:** B – will be able to solve  
**Rule:** Two pure modals cannot be used together.

### Q5.
You (A) / ought respect (B) / your elders (C) / No error (D).

**Answer:** B – ought to respect  
**Rule:** Ought to + V1.

### Q6.
She (A) / should have went (B) / to the office yesterday (C) / No error (D).

**Answer:** B – should have gone  
**Rule:** Modal + Have + V3.

### Q7.
He (A) / cannot to drive (B) / a car properly (C) / No error (D).

**Answer:** B – cannot drive  
**Rule:** Modal + V1.

### Q8.
Does she (A) / can speak (B) / French fluently (C) / No error (D)?

**Answer:** B – Can she speak  
**Rule:** Modal questions do not require do/does.

### Q9.
I (A) / used to played (B) / cricket during my childhood (C) / No error (D).

**Answer:** B – used to play  
**Rule:** Used to + V1.

### Q10.
She (A) / have to complete (B) / her project today (C) / No error (D).

**Answer:** B – has to complete  
**Rule:** Singular subject + Has to + V1.

### Q11.
You (A) / had better to leave (B) / before it gets dark (C) / No error (D).

**Answer:** B – had better leave  
**Rule:** Had better + V1.

### Q12.
He (A) / may be sleeps (B) / in his room (C) / No error (D).

**Answer:** B – may be sleeping  
**Rule:** Modal + Be + V-ing.

### Q13.
The work (A) / must completed (B) / before the deadline (C) / No error (D).

**Answer:** B – must be completed  
**Rule:** Modal + Be + V3 (Passive).

### Q14.
You (A) / need not to worry (B) / about the examination (C) / No error (D).

**Answer:** B – need not worry  
**Rule:** Need not + V1.

### Q15.
He (A) / should not wastes (B) / his valuable time (C) / No error (D).

**Answer:** B – should not waste  
**Rule:** Modal + Not + V1.



# 🔴 PART 4 – Important Structures for Revision

| Structure | Usage |
|---|---|
| Subject + Modal + V1 | Basic modal sentence |
| Subject + Modal + Not + V1 | Negative sentence |
| Modal + Subject + V1? | Interrogative sentence |
| Subject + Modal + Have + V3 | Past reference |
| Subject + Modal + Be + V-ing | Continuous action |
| Subject + Modal + Be + V3 | Passive voice |
| Subject + Ought to + V1 | Advice / Duty |
| Subject + Have/Has to + V1 | Necessity |
| Subject + Had to + V1 | Past obligation |
| Subject + Used to + V1 | Past habit |
| Subject + Had better + V1 | Strong advice |

**Placement Preparation Priority:** Focus on Modal + V1, Modal + Have + V3, Ought to, Have to/Has to, Used to, Had better and modal-based error spotting.
